# 📝 Online Quiz Application (C++)

Welcome to the **Online Quiz Application** repository! This project is a robust, interactive console-based application written in C++ designed to test knowledge across various subjects, manage participant scores, and provide instant performance feedback.

🌐 **Repository Link:** [https://github.com/FariaSajid/Online-Quiz-Application](https://github.com/FariaSajid/Online-Quiz-Application)

---

## ✨ Features

- **Category & Difficulty Selection:** Choose from multiple subjects or difficulty tiers before starting the quiz.
- **Dynamic Question Loading:** Pulls questions, multiple-choice options, and correct answers efficiently.
- **Instant Score Tracking:** Calculates scores in real-time and displays a comprehensive summary report at the end of the quiz.
- **High Score Board:** Keeps track of top scores and participant performance.
- **User-Friendly Interface:** Clean, interactive text-based console menus with robust input validation.

---

## 🛠️ Tech Stack & Concepts

- **Language:** C++
- **Key Concepts:**
  - Object-Oriented Programming (OOP) principles (Classes, Objects, Encapsulation)
  - Data Structures (Vectors, Arrays, Structs) for managing questions and options
  - File I/O handling (for loading question banks and saving high scores)
  - Control flow and input validation
